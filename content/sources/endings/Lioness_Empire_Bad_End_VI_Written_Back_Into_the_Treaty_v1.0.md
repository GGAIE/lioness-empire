# 《母獅帝國》VI 戀人〈被寫回條約〉

2026-11-18｜Bad End 結局稿與實裝交接

## 觸發規則

政治點數在遊戲既有的正式結算中歸零時，立即進入本結局。以結算完成的結果為準。若同一次點數結算會合併數筆變動，讀取合併後的值。合法扣點後的最終值若為負，視同耗盡。原本因點數不足而無法執行的選項，仍依現有規則處理。

結算優先於通往下一場、選單或其他結局的轉場。一次觸發便鎖定，避免連續派發或重複推進。這版將最新指示解讀為所有可正式扣點的遊戲階段適用，包含 Tower。若該段沒有政治點數結算，沿用該段既有流程。

此規則更新專案決議中「歸零規則未定」的部分，並取代舊結局表「僅在 Tower 生存段之前」的限制。其他結局條件與點數算法仍由專案現有規則決定。
