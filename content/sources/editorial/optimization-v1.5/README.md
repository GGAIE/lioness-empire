# 母獅帝國｜Codex 人物風格對話潤飾包 v1.5

目的：讓 Codex 依人物個性，適度修改既有劇情的對話內文。

本版重點：人物風格潤飾＋去除過度條例化／列舉式談判。延續 v1.1 的範圍：只潤飾對話；旁白、動作、劇情結構及遊戲邏輯原則保留。不強制試改一場、不要求逐句重寫、不為呈現個性硬加笑話。

## 使用

把本資料夾放進既有專案，例如 `docs/dialogue-style/`，然後貼：

```text
請閱讀 docs/dialogue-style/CODEX_START.md。
依已確認的人物風格，適度潤飾我指定範圍的既有劇情對話。
同時運用台灣華語的接話方式，並依照 rules/SHORT_DRAMA_REFERENCE.md 檢查條列、宣言式對嗆、無意義的重複解說與硬塞懸念。
保留原意、資訊、情緒走向、事件結果、選項與 CG 對應，旁白原則不改。
已符合角色的台詞保留，不硬加笑話，不擴寫新情節。
本次範圍：［填入章節或檔案路徑］。
請直接修改指定的可維護來源，完成後簡短說明代表性差異與檢查結果。
```

若只想先看對照，將最後一句換成「請先提供平行潤飾稿，不修改原檔」。路徑請依實際位置調整。

本包含十一位人物的確認定位、配角提案及簡式工作流程，未包含前八章完整正文。使用時須讓 Codex 取得真正原稿。
`AGENTS.md` 不直接覆蓋專案原有同名檔；入口會要求讀取本包規則。
