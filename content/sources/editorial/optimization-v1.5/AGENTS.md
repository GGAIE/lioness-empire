# 對話潤飾規則

本資料夾入口為 `CODEX_START.md`；外部專案的適用規則也要讀取。

- 核心目的：按已確認人物風格，適度潤飾既有對話。
- 預設保留旁白、動作、選項、資料欄位與邏輯；不主動進行全面劇情重寫。
- 保留原意、事實、揭露時點、情緒走向、關係、權限與結果。
- 已符合人物的句子可以不改；不強制口頭禪、笑點、死亡笑話、政治交換或金句。
- 不為呈現艾維斯陰謀或其他人特色而新造事件。
- 人物確認定位與執行延伸分開；沒有確認的配角提案不自動套用。
- 原稿用哪種發言標記與角色 ID 就保留，不批次改名或換格式。
- 不覆蓋工作區既有改動，不順手修改引擎、UI、資產或存檔。
- 使用者已要求的修改直接完成，不以試改或另行批准當門檻。
- 對話編輯說明與狀態標籤不進玩家可見文字。
- 驗證按變更所需，報告簡短，交付以修改後文本為主。

- 與人物風格同等重要：去除不必要的條例、列舉、報告腔與輪流總結，依 `rules/NATURAL_DIALOGUE.md` 自然化。
- 可以同區段局部調整對話回合，不得改變資訊擁有者、揭露時點、提議／接受狀態或原稿資料格式。
- 不以刪掉關鍵條件、硬加口頭語或一律短句化來冒充自然對話。

- 依 rules/TAIWAN_MANDARIN_DIALOGUE.md 增加有實際作用的語氣詞及口語連接詞，按人物關係與場合調整。

- 用 characters/CHARACTER_NAMES.md 或 characters/voices.json 辨識中英稿的角色。Ayla “Ella” Gravitz 為正式顯示名，Ella 為暱稱。既有角色 ID 和素材路徑照專案使用。
