# 《母獅帝國》EP05〈攝政成為習慣〉 ACT01〈陛下不見客〉

版本：v1.0｜完整繁體中文 VN 劇本草稿（DRAFT_FOR_REVIEW）｜2026-11-04

依據：EP05 五幕啟動文件 v1.0、專案 00–04 設定整合，以及本次對話最新決議。此稿是**新增候選正式劇情**，並非聲稱以往已有逐字核准的 ACT01 正文。已核准的方向：格拉斯・諾丁漢出身奧辛姆、長期管理王國貿易；艾拉是貨運受害者；工會派系因前階段精簡行動而擔憂失去職位／分配權；三個連續選擇點、兩種運輸路線；ACT02 必定前往奧辛姆；政治點數依選擇組合為 +15／0／−15。

## 幕前資訊與舞台

- 時間：EP04 正式暫時攝政後，EP05 第一日上午至傍晚。
- 地點：王都東北塔一樓接待區、二樓議事室、行政閱覽室、國王內廷外廊。
- 角色：奧莉維亞、艾拉・葛拉維茨（奧特丹魔法學會相關議員，非皇家魔法學院下屬）、芬利、格拉斯・諾丁漢（奧辛姆出身、長期負責王國貿易的宮廷老臣）、宮廷侍從及行政承辦者。
- 工會：奧辛姆航運工會；此處刻畫其船期協調、勞工代表與控制航運接入權的複雜關係，不直接斷言所有基層工人參與阻撓，也不臨時創造已核准的法定壟斷權。
- 基本事實：短期可調用七艘船；已提出運輸需求折算為九艘的運力。艾拉的貨物是九份既有需求內的一批，不能冒出第十份。貨已採購、已取得待運安排，但卡在奧辛姆，奧特丹急缺設備與修繕材料。
- 首要矛盾：精簡行動沒有宣布直接裁撤奧辛姆工會，但傳聞與利害關係使工會幹部、船主、基層人員互相牽制；受害者是照程序辦事的貨主。
- 舊案細節未定：為避免無中生有，僅以『過去船期、戰時優先權、補償責任的爭議』作為已知類型，不指認具體案號、罪行或人名。
- 內部狀態：`C1=SOOTHE|QUESTION`、`C2=CONTACT_UNION|CHECK_CARRIERS`、`C3=KEEP|RIVER`。場景總數五，選項由奧莉維亞作出；其他角色自主行動但沒有玩家選項。

## SC01〈船不是壞了〉
**ID：EP05_ACT01_SC01｜時間：上午｜地點：東北塔一樓接待區→二樓議事室｜POV：奧莉維亞｜有效 Choice：無**

【CG01｜清晨東北塔】

【旁白】東北塔清晨的鐘聲，比王宮的晨鐘慢了半拍。

【旁白】以前奧莉維亞在學院聽鐘，是為了知道下一堂課還有多久；現在鐘聲提醒她，昨天答應處理的公文又多活了一夜。

【旁白】東北塔一樓環形接待區有人候見。侍從將薄薄的來訪名冊交給魔法守衛核對；守衛依既有規則指引來客，沒有自行決定誰可以面見攝政。

【芬利】「殿下，今日第一位不是地方領主，也不是來請您追加軍費的。」

【奧莉維亞】「這聽起來是好消息。」

【芬利】「是艾拉小姐。」

【奧莉維亞】「那就有機會是壞消息了。她通常把好消息寫成論文，把壞消息親自帶來。」

【CG02｜艾拉攜運輸卷宗來訪】

【旁白】艾拉・葛拉維茨進門時手上抱著三份運輸單，肩上的旅行披巾還帶著外面的寒意。她不是為學術演講而來，連寒暄都省了大半。

【艾拉】「我先說，設備買到了。」

【奧莉維亞】「這是妳近來第一句讓我放心的話。」

【艾拉】「也只有第一句。」

【奧莉維亞】「……說吧。」

【艾拉】「奧特丹那邊缺的零件、修繕材料和幾箱實驗設備，已經湊齊。東西在奧辛姆，船也沒有沉，可是一直出不了港。」

【CG03｜貨運文件與設備清單】

【奧莉維亞】「船壞了？」

【艾拉】「沒有。」

【奧莉維亞】「船主跑了？」

【艾拉】「也沒有。」

【奧莉維亞】「那就是貨不見了。」

【艾拉】「貨也在。殿下，我說過了，它們只是動不了。」

【奧莉維亞】「我開始理解妳為什麼親自來。」

【艾拉】「奧特丹的修繕不是把石頭一塊塊疊回去就好。測試架少一組、材料晚一個月，整套工作都可能停。人也不是物資，不能一直要他們等。」

【旁白】她說到最後一句時，聲音低了下來。奧莉維亞記得艾拉談起研究時的眼睛；今天那雙眼睛裡沒有想像未來的光，只有疲倦。

【奧莉維亞】「先坐。今天我們不談再撥一筆錢，也不請妳重新買一次貨。我們先查，已經屬於妳們的東西，究竟被什麼卡住。」

【芬利】「我去調港務副本。只查能交叉核對的資料，不會把傳聞當船期。」

【CG04｜三人將文件攤在議事桌】

【旁白】艾拉稍稍鬆開指節，卻沒有把那疊單據從桌面收走。她需要的不是一句會幫忙，而是貨物確實能抵達。

**場景結果：** 艾拉的貨物受阻事實成立；攝政府同意查證，但未宣布替她保證出貨、也未支付政治成本。

## SC02〈七艘與九份需求〉
**ID：EP05_ACT01_SC02｜時間：上午稍晚｜地點：東北塔行政閱覽室｜POV：奧莉維亞｜Choice Point 01**

【CG05｜奧辛姆航運總圖】

【旁白】芬利送來的副本被分成三疊：可用船舶、已確認貨運，以及始終沒有取得最終日期的船期。每一疊都附著不同官署的印記。

【芬利】「短期內能安排的船只有七艘。按照各方已提交的裝載需求，至少相當於九艘船的運力。」

【奧莉維亞】「也就是缺兩艘。」

【芬利】「是缺兩艘的運力，不是有人藏了兩艘船。若能併艙或錯開日期，仍有部分需求可以先行；但不能保證九份一起完成。」

【艾拉】「我的貨已經在其中，對吧？不要告訴我還要排第十份。」

【芬利】「在其中。它本來就在待運清單上。」

【CG06｜七枚船標與九張貨單】

【奧莉維亞】「那麼到底是誰把能走的船也留在原地？」

【芬利】「港務人員把船期審核交給工會的協調窗口；工會幾個派系對優先順序與責任分擔沒有共識。還有一些真正的運力衝突。這是兩個問題。」

【艾拉】「所以他們談不攏，我們就得一直等？」

【芬利】「目前的效果確實如此。」

【旁白】奧莉維亞翻到後面的附件。上面不是新的貨單，而是有關王都此前『精簡行動』的傳聞摘要。

【奧莉維亞】「……精簡行動？」

【芬利】「消息傳到奧辛姆後，有人擔心港務編制、船期協調職位、甚至工會原有的分配權，都會在下一輪被調整。王都尚未下達針對奧辛姆的裁撤決議，但恐慌已經先行。」

【艾拉】「他們怕被精簡，就讓所有人的貨都卡在港口？」

【奧莉維亞】「這樣搞才會被精簡吧。」

【CG07｜奧莉維亞的無奈表情】

【芬利】「殿下，這個判斷可以留在室內。」

【奧莉維亞】「我只說給你們聽。」

【旁白】她沒有笑很久。那份精簡不是衝著奧辛姆去的，卻已在海港引起一場預先防衛的爭執。她第一次在新的攝政桌前，看見自己曾參與推動的行政調整，如何在遠方被別人重新解讀。

### 【CHOICE POINT 01｜政治態度】
**玩家選擇，僅奧莉維亞可選；二選一。**

**01-A｜「看來我們得去安撫一下。」** → `EP05_UNION_ATTITUDE=SOOTHE`

【奧莉維亞】「先把話說清楚。我們沒有下令裁撤奧辛姆工會，更沒有要一般船員為一份尚不存在的命令失去工作。」

【艾拉】「我想要我的貨，不想要誰因此丟飯碗。」

【奧莉維亞】「正好。我們可以同時把這兩句話帶過去。」

【芬利】「我會把能確認的政策範圍與未定事項分開列明。不承諾將來永不改革。」

【旁白】奧莉維亞點頭。安撫不是替所有人保證一個永遠不會變動的職位，而是承認有些恐懼需要正面回答。

**01-B｜「他們難道不怕貨主真的跑光嗎？」** → `EP05_UNION_ATTITUDE=QUESTION`

【奧莉維亞】「港口不是只有管理船期的人。要是貨主都找別的路，留住那張審核桌又有什麼用？」

【艾拉】「如果真有別的路，我今天就不必來這裡了。」

【芬利】「也許有，只是替代航線未必便宜，更未必能處理所有貨。」

【奧莉維亞】「那至少該查。工會不能把別人沒有選擇，當成自己永遠不必改變的理由。」

【旁白】她看向那些等待批准的船期。合理的勞工保障與壟斷權力之間，也許只隔著一張由誰簽字的表格。

【CG08｜兩條思路投向同一張港口圖】

【共通旁白】不論奧莉維亞如何看待工會，港口的船都沒有因此多出一艘。艾拉的貨還在奧辛姆；唯一改變的，是攝政府準備帶去的第一句話。

**場景結果：** 建立 `EP05_UNION_ATTITUDE`；**本場政治點數 0**；後續需要實際傳達安撫才算工會已被安撫，不能光憑奧莉維亞在房裡說一句話就獲得認同。

## SC03〈精簡行動的回聲〉
**ID：EP05_ACT01_SC03｜時間：中午｜地點：行政閱覽室｜POV：奧莉維亞｜有效 Choice：無**

【CG09｜歷年港務帳冊】

【旁白】接近中午，芬利又送來過去幾年的港務與調度紀錄。奧莉維亞發現，許多爭議的呈報欄都出現同一個名字。

【奧莉維亞】「格拉斯・諾丁漢。」

【芬利】「格拉斯大人長年替父王管理王國的貿易、航運與商務糾紛。奧辛姆是他的故鄉。」

【艾拉】「那他應該最知道工會在想什麼吧？」

【奧莉維亞】「他知道得太多了。」

【芬利】「殿下？」

【奧莉維亞】「每個人不肯認帳時，最後都找格拉斯。久而久之，他們恐怕連對方下句會說什麼都背起來了。」

【CG10｜過往批文與未簽註的船期】

【芬利】「他處理過緊急軍需、民用貨運與船主補償的爭議。並非每次都失敗，但當事人留下了不少沒有結清的不滿。」

【艾拉】「我不是來討他們幾年前的帳的。」

【奧莉維亞】「我知道。可他們現在正拿那些帳，決定妳這批貨能不能動。」

【旁白】窗外有傳令兵騎馬穿過庭園。奧莉維亞忍不住想到，父王從前總有一群人可以替他承接這些問題；如今那些人彼此熟悉，卻未必還有能力一起做決定。

【CG11｜艾拉望向未完成的貨物交接書】

【艾拉】「殿下，有沒有可能就算我們把工會談好了，也還是沒有空位？」

【芬利】「有。七艘對九份需求是真實的限制。」

【奧莉維亞】「那就把事情分開。誰不肯簽、誰沒有船、誰該補償，不能全寫成一句『港口有困難』。」

【CG12｜一份被拆成數欄的調查表】

【旁白】奧莉維亞將格拉斯的名字圈在邊欄。她原本打算派人請這位老臣來東北塔；午前的傳報卻先到一步：格拉斯已帶著奧辛姆案件進宮，請求面見艾爾維爾。

【奧莉維亞】「他還是先去找父王了。」

【芬利】「多年習慣。」

【奧莉維亞】「我猜父王會把他送來這裡。」

**場景結果：** 明確區分真實運力不足、程序卡關與工會內部的權力鬥爭。格拉斯的出身與職務確立，不暗示他涉及貪污或壟斷利益。

## SC04〈國王不見客〉
**ID：EP05_ACT01_SC04｜時間：下午｜地點：國王內廷外廊→東北塔二樓｜POV：格拉斯的結果視角轉奧莉維亞｜Choice Point 02（僅奧莉維亞段）**

【CG13｜老臣在內廷門前等待】

【旁白】格拉斯在國王內廷外廊站得筆直。這條路他走了太多年，連壁燈的火焰往哪側偏，都熟悉得令人厭煩。

【格拉斯】「勞煩通報。奧辛姆有件事，老臣必須向陛下說明。」

【侍從】「陛下已經知道。」

【格拉斯】「那麼，陛下的指示呢？」

【侍從】「請格拉斯大人將完整報告送往東北塔，由攝政殿下處理。」

【格拉斯】「……陛下親口說的？」

【侍從】「是。陛下也說，若案件有超出攝政授權的事項，請依法再呈請。」

【旁白】格拉斯沉默片刻。這不是國王不知如何裁決，而是國王明白地將日常政務交給了已被正式授權的人。

【CG14｜無人打開的門與手中的卷宗】

【格拉斯】「我看著那孩子長大。」

【侍從】「大人？」

【格拉斯】「沒什麼。只是下次來這裡，大概該先問東北塔有沒有空了。」

【旁白】他把卷宗夾進臂彎，轉身離開。內廷的門沒有打開，王權卻並未缺席。

【CG15｜格拉斯抵達東北塔】

【奧莉維亞】「格拉斯？您今天不是要見父王？」

【格拉斯】「殿下消息靈通。」

【奧莉維亞】「他不見客？」

【格拉斯】「他說這件事該找您。」

【奧莉維亞】「所以您繞了半座王宮，最後還是到了我的桌前。」

【格拉斯】「老臣從前替您向陛下請過假，如今倒要來向您請示港口。」

【奧莉維亞】「至少這次我不會為了逃課求您幫忙。」

【格拉斯】「這倒比您當年進步。」

【旁白】兩人都笑了。艾拉坐在桌邊，眼看著一位熟悉故鄉工會的老臣放下文件，終於感覺這場拖延或許能有真正的處理者。

【格拉斯】「殿下，奧辛姆有幾家大船主不願意先承接責任；工會掌握船期協調的人則怕王都精簡以後，連他們的位置都保不住。至於一般船員，大多只怕明天沒有薪資。」

【奧莉維亞】「聽起來是三件不同的事。」

【格拉斯】「正是。他們現在卻要把三件事綁在一起談。」

### 【CHOICE POINT 02｜格拉斯的準備】
**玩家選擇；不直接變更政治點數或路線。**

**02-A｜「那就請工會代表過來，把話說清楚。」** → `EP05_PORT_PREP=CONTACT_UNION`

【奧莉維亞】「我想先知道，誰能代表真正擔心失業的人。」

【格拉斯】「好。老臣會聯絡能說話的人，但不保證所有派系都樂意同桌。」

【艾拉】「只要有人願意承認貨主也在受損，我就願意聽。」

【旁白】格拉斯在名冊上圈出數位可聯絡的代表。這份準備將使 ACT02 的協商較早取得會談入口，但不能代替正式和解。

**02-B｜「能換一家嗎？格拉斯，你不是說你名單很多。」** → `EP05_PORT_PREP=CHECK_CARRIERS`

【奧莉維亞】「至少替艾拉查一條不必等同一張簽字桌的路。」

【格拉斯】「名單很多，能接這批貨的可不一定多。若走內河，還要看靠泊、轉運與承保。」

【艾拉】「只要不是讓我再買一次設備，我願意看報價。」

【奧莉維亞】「先查條件，不等於現在就改約。」

【旁白】格拉斯列出其他承運者與河港窗口。這份準備將使 ACT02 的河運核實較快，但不自動證明所有河道都能通行。

【CG16｜三人在同一張桌前比對兩套方案】

【共通旁白】格拉斯抬頭看了奧莉維亞一眼，像是在確認她真的要自己承擔這個決定，而不會轉身找國王替她收尾。

【格拉斯】「殿下，無論走哪條路，我們都得去奧辛姆。坐在王都說服不了每一個掌握碼頭的人。」

## ACT02 接續條件演出（不是 ACT02 完整正文）

### A｜C3=KEEP：原體系和解，政治點數 0

ACT02 奧辛姆：無論 C1 是 SOOTHE 還是 QUESTION，格拉斯透過港務副本、工會代表與船主，確認艾拉的貨物進入可履行的原航運排程。船數仍是七艘，不聲稱九份同時得到滿足。C1=SOOTHE 時以政策釐清開場，工會較願聽；C1=QUESTION 時對話較硬，但仍可透過可核對的契約談成。C2 改變先有工會窗口或先有替代運力資料的細節。貨物完成運送，**政治點數變化 0**。

### B｜C1=SOOTHE，C3=RIVER：安撫後河運，政治點數 +15

ACT02 奧辛姆：格拉斯向工會代表提交精簡政策的正式澄清，工會代表確認接收；以不要求工會全體背書新承運商為前提，約定基層人員原有權益、轉運交接與申訴窗口。另一承運商核實內河船次，艾拉的貨物較早抵達奧特丹。這是**有效安撫與更快交貨兩項成果同時成立**時的政治收益，於 ACT02 SC05 一次結算 **+15**。若後續正式劇本調整成安撫失敗，不能硬發 +15；應先回到事件設計審核，而非自行更改已確認的兩路線結果。

### C｜C1=QUESTION，C3=RIVER：質疑後河運，政治點數 −15

ACT02 奧辛姆：奧莉維亞繞開原承運體系，雖然替代河運使艾拉貨物較快抵達，但工會解讀她先前對壟斷的質疑與改約為施壓／將來裁撤的前奏。攝政府必須支付額外的政治關係與執行成本，於 ACT02 SC05 一次結算 **−15**。不得把 −15 說成艾拉因此受罰，貨物照樣送達。
