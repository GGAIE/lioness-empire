## 正式結算

- C1 `SOOTHE` + C3 `RIVER`：**+15 政治點數**（ACT02 確認安撫成功及貨物更快運達後，一次性）
- C1 `QUESTION` + C3 `RIVER`：**−15 政治點數**（ACT02 合約完成與貨物交付後，一次性）
- C3 `KEEP`：**0 政治點數**（不論 C1、C2）
- C2 只影響前置資料與現場演出，不直接改變政治點數。
- 所有組合 ACT02 都前往奧辛姆；ACT01 貨物尚未送達，ACT02 方才收單。
- 動盪值未由本次對話核定，須與專案總規則對照後再定，不能把政治 +15 自動視為動盪 0。
