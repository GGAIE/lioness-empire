# SC01〈山崩之前〉
**時間：與 EP06 ACT01 後段重疊｜地點：卡巴岡德北部山谷｜POV：艾琳達｜選項：無**  
**BGM：〈The Last Hunt〉／低音弦樂、擊鼓、碎裂金屬聲。**

【CG-01｜山谷中的格拉斯哥】

山谷忽然傳來轟響。高大的身影踏碎一排早已無人居住的石屋遺址，將碎石踢向兩側。格拉斯哥站在荒涼的山谷裡，皮膚與甲殼上嵌著岩屑，胸腔呼吸的聲音彷彿石磨碾過地面。

艾琳達站在巨人前方。她的披風已經裂了邊，鎧甲右肩被打出深深的刮痕，裂光之盾仍牢牢扣在手臂上。

**艾琳達：**「你知道嗎？我認識你，比認識第六團裡不少新人還久。」

格拉斯哥朝她咆哮。

**艾琳達：**「嗯，我也很想念你。尤其是你每年替我們拆的那幾條路。」

她側身避開掃來的巨掌，岩層在腳邊迸裂。

【CG-02｜裂光之盾迎擊巨掌】

格拉斯哥並不是突然出現的怪物。多年以前，山地商旅開始流傳巨人出沒的消息；後來是牲畜、倉庫、道路、農田，最後連人們熟悉的村莊也一再受到波及。第六團曾數度追擊，卻因山區艱險與戰事牽制，沒有完成持續封鎖。尤其大戰期間，任何一支能上前線的部隊都很難被長期留在深山裡。

這回不同。趁著戰線稍有餘裕，艾琳達安排疏散山谷周邊居民，讓士兵守住外圍通道。她沒有要求部下替她承受最後的正面決戰，因為這狹窄地勢無法讓大隊人馬有效展開。

她望向背後的山壁。數日勘查標出的裂縫，經過格拉斯哥幾次猛烈撞擊已更為鬆動。

**艾琳達：**「說起來，我本來想用很體面的方式結束這件事。」

格拉斯哥抓起巨石擲來。

**艾琳達：**「但你好像對體面過敏。」

巨石撞在盾面外緣，艾琳達順勢翻身，肩頭卻重重碰上岩柱。她咬住牙，感覺肋側火辣辣地疼。

【CG-03｜艾琳達負傷後仍站起】

**艾琳達：**「……醫官看見這樣，肯定又會碎唸。」

她沿著預先看好的窄谷退去，讓巨人追入兩側高壁之間。外圍的號角傳來短短兩聲，那是居民已經撤離危險區的信號。

艾琳達停下腳步，看著巨人站穩。

**艾琳達：**「好。現在這裡沒有別人了。」

她把盾牌略微放低，從背後抽出長弓與箭矢。她瞄準的不是巨人，而是上方岩壁一處已經鬆裂的支撐點。弓箭不是足以摧毀完整山峰的神兵；最後一擊只是在既有崩裂和巨人踏動造成的壓力下，讓破碎岩層失去最後的支撐。

格拉斯哥又一次抬起手。

**艾琳達：**「格拉斯哥。這麼多年來，真是承蒙照顧。」

她鬆開弓弦。

【CG-04｜最後一箭射向岩壁裂縫】

箭矢沒入裂口。先是砂礫掉落，接著裂紋迅速延展。上方一塊巨石先動了，隨即拖著更大片岩層往下崩落。

格拉斯哥抬頭，往谷口猛衝。第一塊巨岩砸中他的肩部；第二波落石將狹窄的退路截斷。巨人還想撐起身體，山壁已整片壓下。

【CG-05｜格拉斯哥被山崩吞沒】

艾琳達拉起盾牌，卻仍被飛散的碎石與衝擊波掀翻。她撞上岩面，再重重跌落地面。

四周終於安靜時，只有遠處幾顆石子還在滾動。

她試著支撐自己坐起來。

失敗。

她再試一次，勉強靠住石壁，緩緩吐了口氣。

**艾琳達：**「……好吧。算你贏了半回合。」

遠處傳來第六團的號角。士兵正向她所在的地方趕來。巨人的身影已經完全消失在巨石下。

艾琳達望向山谷另一端，隱約還能看見遭破壞的田地和荒廢的屋舍。這場勝利阻止了往後的襲擊，卻不能讓那些地方立刻恢復。

**艾琳達：**「這麼多年，終於讓你消停了。」

她低頭看著無法順利抬起的手臂。

**艾琳達：**「……但我也得消停幾天了。」

【CG-06｜勝利之後受傷的艾琳達】

# SC02〈一場非常必要的視察〉
**時間：ACT01 結束後，奧莉薇雅仍未得知最後戰果｜地點：王都東北塔、塔頂、飛船、卡巴岡德駐地｜POV：奧莉薇雅｜選項：無**  
**BGM：〈A Convenient Inspection〉／俏皮木管、輕鋼琴，抵達時轉為低弦。**

【CG-07｜東北塔的踱步】

王都。東北塔。

奧莉薇雅站在茶几旁，凝視一疊明明已經看過卻還是得簽的文件。她看了左邊一頁，又看看右邊的備註，最後決定站起來走一圈。

芬利正在整理奧特丹的貨運紀錄，聽見她第五次經過窗邊，終於抬頭。

**芬利：**「殿下，您是在找遺失的東西嗎？」

**奧莉薇雅：**「沒有。我在思考。」

**芬利：**「思考什麼？」

**奧莉薇雅：**「國家大事。」

芬利看了看沒少半張的公文。

**芬利：**「國家大事看來都在桌上。」

**奧莉薇雅：**「所以我才要走遠一點思考。」

她又踱了半圈，忽然停下來。

**奧莉薇雅：**「對了，莉姆斯不是來求援了嗎？」

**芬利：**「是，第六團討伐即將展開的請求。您在上一場會談已有初步決定。」

**奧莉薇雅：**「這種大事，攝政公主是不是應該親自視察？」

**芬利：**「聽起來很盡責。」

**奧莉薇雅：**「是不是？」

**芬利：**「尤其剛好能離開這張辦公桌。」

**奧莉薇雅：**「……你能不能讓我當一次真正心懷天下的人？」

**芬利：**「您確實心懷天下，只是天下的位置恰好在辦公室外面。」

奧莉薇雅忍不住笑了，披上出行外套。

**奧莉薇雅：**「就這麼定了。我要去卡巴岡德。」

**芬利：**「我能替您叫飛船。到東北塔塔頂就能搭。」

**奧莉薇雅：**「我們樓上還有這種服務？」

**芬利：**「一直有接駁平台。」

**奧莉薇雅：**「你怎麼不早說？」

**芬利：**「因為您以前沒問。」

**奧莉薇雅：**「你的頂嘴能力最近進步很多。」

**芬利：**「都承蒙殿下平日指導。」

【CG-08｜塔頂飛船接駁】

飛船沿著王都上方緩緩升起。起初，奧莉薇雅還饒有興味地看著雲層、河道與山地輪廓。接近卡巴岡德後，她卻看到山谷大片裸露的岩面、被切斷的道路，以及沿山坡延伸的收容帳篷。

她坐正了些。

**奧莉薇雅：**「……這看起來不像正在準備討伐。」

【CG-09｜飛船俯視封閉山道與災民營】

飛船降落在第六團可供接駁的安全場地。莉姆斯匆匆迎來，見到奧莉薇雅時顯然十分驚訝。

**莉姆斯：**「殿下？您怎麼親自來了？」

**奧莉薇雅：**「妳都來求援了，我總得來看看。艾琳達呢？討伐什麼時候開始？」

莉姆斯微微一怔。

**莉姆斯：**「……已經結束了。」

**奧莉薇雅：**「咦？」

**莉姆斯：**「格拉斯哥已經死亡。最後一戰由艾琳達團長完成。」

**奧莉薇雅：**「我才離開王都多久？」

**莉姆斯：**「殿下抵達之前，戰鬥已經結束。」

奧莉薇雅看向遠處那片崩塌的山壁。

**奧莉薇雅：**「……那座山，也是她弄的？」

**莉姆斯：**「她用箭引發山崩，將巨人埋在下面。」

**奧莉薇雅：**「我以為她是騎士團長，原來還兼做拆山工程？」

莉姆斯差點笑出聲，卻又有些猶豫。

**莉姆斯：**「團長也受傷了。醫官要她至少休養七天。」

奧莉薇雅的笑容收了些。

**奧莉薇雅：**「很嚴重？」

**莉姆斯：**「沒有生命危險，但目前不能下床處理外勤。」

**奧莉薇雅：**「先帶我去看看她。」

【CG-10｜莉姆斯在接駁場告知討伐結果】

病房內，艾琳達半靠在床頭，肩膀有固定繃帶，桌邊放著明顯過量的報告。

**奧莉薇雅：**「聽說妳把一座山拆了？」

**艾琳達：**「只拆了一部分。」

**奧莉薇雅：**「喔，那還好。」

**艾琳達：**「剩下的應該還能用。」

奧莉薇雅笑出聲。

**奧莉薇雅：**「我本來想來看妳怎麼討伐巨人。」

**艾琳達：**「那妳來晚了。下次替妳留一頭？」

**奧莉薇雅：**「謝謝，不必這麼有禮貌。」

奧莉薇雅在床沿旁坐下，語氣放輕。

**奧莉薇雅：**「傷得怎麼樣？」

**艾琳達：**「醫官說至少七天不能亂跑。我原本想跟他談成三天。」

**奧莉薇雅：**「談成了嗎？」

**艾琳達：**「他現在不准我自己走去找他談。」

**奧莉薇雅：**「那我看這次談判是他贏了。」

艾琳達笑了一下，立刻按住肋側。

**艾琳達：**「……別害我笑，真的會痛。」

**奧莉薇雅：**「好好好，我認輸。」

**艾琳達：**「聽說妳是來視察的？」

**奧莉薇雅：**「非常正式的視察。」

**艾琳達：**「那就麻煩妳先出去看看。倉庫、收容營、斷路和教會的醫療站，莉姆斯都熟。看完我們再談，免得我光說妳也不信。」

**奧莉薇雅：**「那妳趁機休息。」

**艾琳達：**「我會努力做出休息的樣子。」

**奧莉薇雅：**「妳最好是真的。」

【CG-11｜兩位表親在病房初次打招呼】

**轉場：奧莉薇雅隨莉姆斯巡視，病房沒有立即開始談判。**

# SC03〈空倉與名冊〉
**時間：同日午後｜地點：軍需倉庫 → 受災道路 → 臨時收容營 → 聖光會醫療站 → 重建地圖台｜POV：奧莉薇雅｜選項：無**  
**BGM：〈Homes That Are No Longer There〉／鋼琴與抑制的弦樂。**

【CG-12｜空掉的第六騎士團倉庫】

第六團的倉庫比奧莉薇雅預想的還大，也比她預想的還空。幾列木架上只剩舊封條，角落的少量糧袋都做了配額註記。

**奧莉薇雅：**「這裡收拾得真乾淨。」

**莉姆斯：**「主要是因為快沒有東西可以收拾了。」

**奧莉薇雅：**「妳們團長的幽默感是不是會傳染？」

**莉姆斯：**「我們每天都在努力適應。」

莉姆斯取出兩份帳表：多年戰事與延遲補給造成的既有庫存缺口，以及格拉斯哥討伐、疏散和災害救助額外消耗的部分。不是每一個問題都能歸咎於山崩。

**【ACT01 承接台詞：讀取上一幕五選一結果，只播放對應一條】**

- **若 ACT01 選項一（先查核討伐情報）：** 莉姆斯指著追加軍情核對註記說：「王都先請我們補齊軍情，團長已經把封鎖與疏散的細節留下紀錄。至少這回不用從傳言開始查。」奧莉薇雅：「很好，讓我知道我當初沒有白問。」
- **若 ACT01 選項二（先答應教會協助）：** 莉姆斯說：「教會接到王都先前願意配合的消息後，聯絡地方救濟站的程序比較順利。」奧莉薇雅：「先讓人有藥可用是好事。只是後面的授權要另外談。」這項不能直接等於 ACT02 任一 A 已選。
- **若 ACT01 選項三（先批准王都出兵）：** 莉姆斯說：「王都援軍的調度命令已送到，但最後決戰結束得太快，沒趕上那一刻。現在我們正在協調封鎖線和安全護運是否仍需要他們。」奧莉薇雅：「能幫忙護送也是幫忙，至少別讓前面準備白費。」不得把援軍畫成幫艾琳達擊殺格拉斯哥。
- **若 ACT01 選項四（先壓下奧特丹問題）：** 莉姆斯說：「王都這幾天沒有再追加討伐方面的新部署。」奧莉薇雅：「嗯。那先從眼前有的帳開始查。」奧特丹調查的後果留給 ACT03，不在本幕定罪。
- **若 ACT01 選項五（明日再議）：** 莉姆斯說：「我們當時還在等王都回覆，只能先照原定計畫疏散。」奧莉薇雅：「看來我這趟至少該把情況看完整。」不在 ACT02 重算上一幕的扣點。

**【承接結束，回到 SC03 共通內容】**

**奧莉薇雅：**「這些倉庫原本就不滿？」

**莉姆斯：**「是。戰時我們優先把東西送往更需要的防線，這一帶的農地也一直被格拉斯哥破壞。這回只是終於全擠在一起。」

**奧莉薇雅：**「……所以莉姆斯送的求援信，本來就是怕這種情況。」

**莉姆斯：**「團長預估過討伐的後勤壓力，只是沒人能把之後每條斷路都算準。」

接著她們走到被落石阻塞的道路。石堆切斷兩個聚落之間的舊路，新的臨時通道只能容許小隊人馬通行。遠處農田被碎石覆蓋，灌溉引水溝失去連接。

【CG-13｜斷路與被掩埋的農田】

**奧莉薇雅：**「這條路要修多久？」

**莉姆斯：**「我不敢亂說。得先等勘查，才能知道哪裡還能動工。」

**奧莉薇雅：**「比我想的麻煩。」

**莉姆斯：**「團長也是這麼說的。然後她就去拆了另一面山。」
