# 亞丁・格倫｜Adin Glen

- 身分：聖光會年輕男性神職代表，長期駐莎莉雅領地，熟悉村莊與居民。
- 個性：真誠、勤奮、慈悲、對教會使命極有信心；善於現場救濟，但缺乏高層政治交涉經驗。
- 劇情功能：奧莉維亞利用稱讚與公共讚譽，讓他把地方需求提升為需要教會核准的正式救濟方案。他不是蠢人或壞人，也沒有無限額度的教會財權。
- 外型：年輕成年男性，淺灰金髮、灰藍眼、修長體型。象牙白與古金的聖光會高領長袍、金線太陽輻紋、短披肩、腰帶、手套、長靴。
