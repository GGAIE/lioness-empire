# ACT04 Sacred｜四選項與莎莉雅事件判定 v1.0

## 固定結果
1. 寒冰之眼召喚完成、巨龍確實現世。
2. 艾莉西亞以精靈封印術將其重新封印，無玩家操縱或死亡結局。
3. 莎莉雅領地數座村莊遭重大寒害，並非封印成功就自動復原。
4. 聖光會未能中斷召喚，但有人道救濟工作成果。
5. 玩家唯一選擇者：奧莉維亞。
6. ACT04 透過**慈善救濟**取得教會支援，不是賠償、認罪或判決責任；ACT05 才進一步討論教會的高階魔法危機處置能力與制度權限。

## 四選擇的有效條件
| ID | 玩家選項 A | B | C | 有效答案 |
|---|---|---|---|---|
| M01 | 公開邀請亞丁說明救濟使命、王室見證 | 王室自行接管 | 僅內部回報 | A |
| M02 | 僅臨時慰問 | 把莎莉雅的重建清單列為救濟延續項目 | 先刪減地方需求 | B |
| M03 | 教會救濟與艾莉西亞封印分別公開表揚 | 不提教會 | 只公告危機結束 | A |
| M04 | 取得亞丁職務內承諾＋上級批准與交付時程 | 僅口頭善意 | 假冒教會上級全額批准 | A |

- 每次有效答案加一個隱藏 `RELIEF_LEVERAGE_SCORE`。**分數在最終 SC05 結算，不於遊戲前台顯示。**
- 四次答案的順序刻意分散，避免玩家以選項字母猜解。正式遊戲可再打散選項順序，但必須同步更新 resolver。
- 4/4 => BIG_SUCCESS；3/4 => SUCCESS；2/4 => SMALL_FAILURE；0-1/4 => BIG_FAILURE。
- `SHALIA_CLEAR_DELTA=1` 當且僅當 `RELIEF_LEVERAGE_SCORE >= 3`。不重複加分、不刪歷史已有 CLEAR。
- 4/4 擴大教會救濟支援，3/4 核心救濟成立，2/4 援助有限，0–1/4 幾無新增可落地承諾。
- 政治資源、動盪值及教會實際資金數額 **TBD / OPEN**，避免違反政治點數為資源成本、取得資源會增加動盪的既定規則。
- 亞丁只能在其職務授權範圍承諾，需經聖安奴加斯財務與管理程序才能正式擴大調撥；有效選項不是「亞丁一人簽下無限支票」。

## 無影響選項
F01–F14，各三選一、合流、不寫任何旗標、政治資源或人際量表。**在 UI 與有效選項使用相近樣式與相近字數**，達成掩護效果，不加入「本選項無影響」標示。
