## 一、版本硬限制與敘事原則

1. 奧莉維亞與芬利在五年前曾共同研究薩克迪的衰亡。兩人是平等的學術夥伴；芬利不是單方面授課者。
2. 傳統史學將薩克迪滅亡歸因於外部威脅；兩人根據官署、調度及物資紀錄提出制度內耗假說，但**未能證實為唯一原因**。
3. 當年有關鍵資料未能合法調閱，因此芬利至今仍想完成研究；不得憑空將推論寫成已被證實的歷史定論。
4. 本幕以薩克迪的故事為中心，中段加入安度因現況插曲，先談 ACT01 攝政典禮上的三名官員，再出現一壺茶因新舊勤務權責交接而延誤的事件。
5. 三名官員暫定姓名：路德維克・凡・艾斯特（文書協調）、馬提厄・德・瓦爾（商務及運輸許可）、赫爾曼・馮・里特堡（人事協調）。不得未經查證便定性為犯罪者。
6. 六次選擇中，前五次均為三選一的角色對白分歧，選後立刻匯合，不變更任何持續數值、動盪或 CLEAR。

## 三、完整劇情

### SC01｜教科書裡的滅亡

**場景：** 攝政書房，深夜。承接 ACT01 結尾。  
**參與者：** 奧莉維亞、芬利。

**【CG01｜燭光下的雙人研究】**

攝政書房的燭火靜靜燃燒著。桌上攤開兩疊資料。一疊是安度因剛被裁撤的舊行政機構沿革；另一疊則是五年前留下的學院研究筆記，封面角落已經磨舊。

奧莉維亞將那本筆記推向芬利。

**奧莉維亞：**「你還記得我們以前在學院研究過的薩克迪嗎？」

芬利看了筆記一眼，像是某段許久未翻動的記憶忽然被喚醒。

**芬利：**「魔導帝國薩克迪？當然記得。」

**奧莉維亞：**「我今天忽然想起來。歷史課本總說，薩克迪是被外敵打垮的。」

芬利拉開椅子坐下，翻開筆記第一頁。

**芬利：**「這也是大多數人願意記住的版本。」

**【CG02｜學院研究筆記特寫】**

紙頁之間夾著舊日的抄錄紙條與地圖。年輕時的筆跡，有些鋒利，有些倉促。

**奧莉維亞：**「因為簡單。帝國強盛、外敵入侵、防線崩潰、首都陷落。故事到這裡就結束了。」

**芬利：**「而且很有戲劇性。人們總喜歡把一個帝國的死亡，歸結給一場足夠壯觀的戰爭。」

**奧莉維亞：**「就像只要找到最後一根斷掉的樑柱，就假裝整棟房子不是早就空心了。」

芬利抬頭看她。

**芬利：**「妳還真是一點都沒變。」

**奧莉維亞：**「哪一點？」

**芬利：**「還是喜歡在第一頁就把教科書推翻。」

**【CG03｜薩克迪教科書式滅亡想像圖】**

畫面彷彿被兩人的記憶拉向遙遠過去。高牆、魔導尖塔、覆蓋帝都的巨型結界。遠方黑潮般的敵軍壓向城下，天空中的魔法光流彼此撞擊。

這是後世最熟悉的薩克迪：一個在戰火中被擊倒的帝國。

**芬利：**「如果只看這些圖像，誰都會相信薩克迪是亡於外部威脅。」

**奧莉維亞：**「但我們當年越查越覺得，不對勁。」

**芬利：**「因為有些紀錄，比戰爭更早。」

**CH01｜三選一（無數值效果）**

- **A「外敵或許真的很強，但那不是全部。」**  芬利：「最麻煩的往往都不是『假的』，而是『只說了一半真的』。」
- **B「歷史書最擅長把複雜的事講成一句話。」**  芬利：「畢竟一句話比較容易被背下來。」
- **C「被記住的，往往只是最方便記住的結果。」**  芬利闔起筆記又翻開：「所以研究者才得負責去找那些不方便的部分。」

**【共同匯合】**

奧莉維亞把椅背稍稍往後靠。

**奧莉維亞：**「那就從最簡單的地方開始。若薩克迪不是單純亡於外敵，那它是先從哪裡壞掉的？」

芬利將手指放在筆記中的一條標註線上。

**芬利：**「從『例外』開始。」

**【CG04｜研究進入下一章】**

燭光落在幾個被圈起來的舊註記上。文字僅供劇本敘述，CG 不繪製可讀字樣。

**→ SC02**

### SC02｜例外如何成為制度

**場景：** 攝政書房與薩克迪歷史想像畫面。

**【CG05｜薩克迪早期繁榮與官署運作】**

芬利翻到下一頁。畫面中的薩克迪，不再是末日中的帝都，而是仍然井然運作的黃金時代。整齊的官署、繁忙的魔導工坊、往來不絕的運輸隊。

**芬利：**「薩克迪最早並不臃腫。相反地，它的行政體系曾經非常有效率。」

**奧莉維亞：**「所以問題不是『有官署』，而是『官署怎麼變成後來那個樣子』。」

**芬利：**「沒錯。」

**【CG06｜戰時新增調度機構】**

筆記中的下一段記錄，是一場邊境危機。前線壓力驟增，舊有制度來不及應變。於是帝國設立了新的戰時調度機關，負責直接統合魔導工坊、物資與運輸。

**芬利：**「第一個新增機構，是為了救火。」

**奧莉維亞：**「而且很可能真的救到了。」

**芬利：**「是啊。也正因為它曾經有效，所以沒有人願意撤掉。」

**奧莉維亞：**「因為一旦撤掉，下次有危機時，誰也不想背責任。」

**【CG07｜監督機構再度增殖】**

新的調度機關建立後，又出現另一個問題：誰來監督這個臨時獲得大量權限的新機構？於是新的監督單位誕生。監督單位本身又需要審核、記錄與安全確認。一層，接一層。

**奧莉維亞：**「最開始只是例外處理。後來成了常設機構。」

**芬利：**「常設機構久了，又會長出自己的例外。」

奧莉維亞忍不住笑了一下，但很快又收斂。

**奧莉維亞：**「真難看。」

**芬利：**「而且很真實。」

**CH02｜三選一（無數值效果）**

- **A「當時的統治者，可能根本沒有其他選擇。」**  芬利：「我也傾向這麼看。至少一開始是如此。」
- **B「真正的問題不是設立，而是沒有人規定何時撤除。」**  芬利：「五年前妳就在筆記邊上寫過同一句話。」
- **C「也許從那時起，就有人學會利用危機擴張權力。」**  芬利：「有可能，但我們還沒有足夠證據，不能把所有制度都解釋成惡意。」

**【共同匯合】**

奧莉維亞伸手把筆記壓平。

**奧莉維亞：**「所以薩克迪的可怕之處，不是它做錯了一件大事。」

**芬利：**「而是它一次又一次地做了『當時看起來合理』的小事。」

**奧莉維亞：**「直到這些小事彼此疊在一起，變成沒有任何人能拆掉的東西。」

**【CG08｜層層機構示意構圖】**

帝國的行政結構像疊高的塔，一層層架在原本的地基之上，愈來愈高，也愈來愈沉。

**→ SC03**

### SC03｜誰也沒有犯錯

**場景：** 攝政書房與薩克迪歷史想像畫面。

**【CG09｜等待核准的魔導物資】**

芬利把研究筆記翻到一張被反覆標註的運輸紀錄。畫面浮現出薩克迪中後期的運輸關卡。裝載魔導核心的車隊停在高門下，車夫、軍務官、工坊代表與審查人員都站在原地，誰也沒有離開，誰也沒有放行。

**芬利：**「這是我們當年最在意的一段。」

**奧莉維亞：**「最後一批魔導核心？」

**芬利：**「對。工坊完成製造，軍方提出請求，運輸也準備好了。問題是，每個機構都還有自己的核准程序。」

**【CG10｜每個人都在履行職責】**

畫面拉近。有人檢查安全風險，有人核對帳冊，有人確認用途，有人等待上級覆核。每個人的表情都嚴肅而認真。沒有偷懶，沒有醉酒，也沒有明顯的貪污嘴臉。只有等待。

**奧莉維亞：**「最糟糕的地方在於，這裡看起來不像陰謀。」

**芬利：**「因為多半不是。」

**奧莉維亞：**「每個人都在做自己的工作。」

**芬利：**「是啊。可整個國家卻沒把該做的事做完。」

**【CG11｜前線等待中的防線】**

遠在前線，法陣逐漸黯淡。守軍仰望著不再穩定的結界，仍然等待那批理應抵達的魔導核心。

**芬利：**「如果一個帝國能造出足以改變戰局的東西，卻無法讓它抵達需要的地方——」

**奧莉維亞：**「——那麼輸掉戰爭的，未必是軍隊。」

芬利看著她，像是某段五年前的對話重新接上。

**CH03｜三選一（無數值效果）**

- **A「最該負責的是決定程序的人。」**  芬利：「這是一種答案。但那個『決定的人』往往不只一個。」
- **B「照程序做事的人，也不能永遠說自己沒有責任。」**  芬利：「而這正是最難判定的部分。」
- **C「也許真正的問題是，這件事根本不能只怪某個人。」**  芬利輕聲道：「當年妳也是這麼想，才會繼續往下查。」

**【共同匯合】**

**奧莉維亞：**「一個國家真正危險的時候，也許不是有人公開叛國的時候。」

**芬利：**「而是每個人都依法辦事，國家卻還是什麼都辦不成的時候。」

奧莉維亞沒有立刻接話，只看著車隊停在門前的想像圖。那是一幅沒有尖叫、沒有屍體、沒有烈火的崩潰畫面。卻比戰場更令人不安。

**【CG12｜沉默停滯的車隊】**

靜止的車輪、未啟動的魔導封箱、站在各自位置的人們。整個帝國像是卡在一個無法前進的瞬間。

**→ SC04**

### SC04｜笑容、官員與一壺茶

**場景：** 攝政書房，深夜稍晚。  
**說明：** 先談三名當代官員，再安排茶點插曲。茶點延誤係 EP03 精簡後的職權交接問題，不得暗示已撤單位仍持續非法運作。

**【CG13｜回到當下的攝政書房】**

歷史的影像退去，燭光重新落在書房裡。奧莉維亞抬手按了按眉心。

**奧莉維亞：**「說起來，今天倒有幾個人特別高興。」

**芬利：**「攝政典禮上的那幾位？」

**奧莉維亞：**「路德維克、馬提厄、赫爾曼。前陣子王宮才精簡了一批冗餘機構，他們今天卻笑得比誰都熱情。」

**芬利：**「妳懷疑他們？」

**奧莉維亞：**「懷疑還談不上。我只是覺得，他們未免太早知道該向誰示好了。」

**【CG14｜三名官員的回想鏡頭】**

畫面閃回至白日的祝賀廳。路德維克溫和地說，自己願意全力配合文書協調；馬提厄自然地談起商務與運輸流程可以由他親自協調；赫爾曼則非常在意往後人事與請示路徑。

**芬利：**「也許他們確實只是高興自己終於知道，之後該向誰報告。」

**奧莉維亞：**「我不否認。」

**芬利：**「又或者，他們高興的是，權力重新分配的時候，自己還能站在離桌面最近的位置。」

奧莉維亞看向桌邊那幾份今天才送來的履歷與交接摘要。

**奧莉維亞：**「薩克迪晚期，也有這種人嗎？」

**芬利：**「我懷疑一直都有。只不過，有些人想要的是利益，有些人想要的是穩定，還有人只是想讓工作繼續做下去。」

**奧莉維亞：**「聽起來，沒有哪一種特別邪惡。」

**芬利：**「真正可怕的制度，往往不用靠邪惡維持。」

**【CG15｜插曲開始：侍從來報茶點】**

門外傳來敲門聲。一名侍從推門入內，手中沒有茶盤，只有一份臨時文書。

**侍從：**「殿下，您先前吩咐的熱茶，可能還需要一點時間。」

奧莉維亞看向空杯。

**奧莉維亞：**「一壺茶也需要時間？」

侍從有些尷尬地低下頭。

**侍從：**「今日攝政書房正式啟用，原本茶點與值夜勤務的交接，目前由不同單位暫時共同處理。內廷與攝政辦公室對夜間核准程序的理解……略有不同。」

芬利慢慢把手中的羽毛筆放下。

**奧莉維亞：**「所以我的茶，現在卡在哪一關？」

**侍從：**「還在確認究竟該由哪一邊核准。」

短暫的沉默後，芬利偏過頭，明顯在忍笑。

**奧莉維亞：**「你如果笑出來，我就讓你去填那份申請。」

**芬利：**「我沒有笑。我只是突然覺得，薩克迪的研究很有現實意義。」

**CH04｜三選一（無數值效果）**

- **A「不用了，我自己泡。」**  侍從愣了一下：「殿下，這恐怕——」奧莉維亞：「放心，我只是想先喝到茶。」
- **B「那就照程序來吧。」**  芬利抬眉：「真有耐心。」奧莉維亞：「我想看看這壺茶多久才會抵達。」
- **C「芬利，你不是會魔法嗎？」**  芬利：「會。但我不確定用魔法泡茶，算不算繞過程序。」奧莉維亞：「那就更值得試了。」

**【共同匯合】**

侍從退下後，書房重新安靜下來。芬利看著門口。

**芬利：**「不過，那個侍從其實沒做錯什麼。」

**奧莉維亞：**「我知道。」

**芬利：**「內廷想確認職責範圍，攝政辦公室也想確認新的交接程序。誰都不是故意在拖延一壺茶。」

**奧莉維亞：**「可結果就是，茶送不進來。」

**芬利：**「薩克迪很多事情，大概也是這樣開始的。」

**【CG16｜茶杯與研究筆記並置】**

**奧莉維亞：**「所以我不該只問，這些官員今天是不是對我太熱情。」

## 五、工程實作規格

### 一般分歧

```pseudo
for scene in SC01..SC05:
    play(scene.intro)
    choice = await select(three_visible_flavor_options)
    play(scene.branch[choice])
    play(scene.common_merge)
    goto(next_scene)
```

### 芬利 F1 分歧

```pseudo
F1_STATE = NOT_STARTED

on EP04_ACT02_SC06:
    if choice == "我知道塔瑪拉那邊好像有。":
        political_points -= 10
        F1_STATE = ACTIVE
    else if choice == "裝傻。":
        F1_STATE = DECLINED

on EP04_ACT03:
    if F1_STATE == ACTIVE:
        play F1_SC02  # 塔瑪拉依法協助取得資料；無新選項、無額外成本
        F1_STATE = MATERIAL_OBTAINED

on EP04_ACT04:
    if F1_STATE == MATERIAL_OBTAINED:
        play F1_SC03  # 芬利完成研究並製作巡邏／通報用途魔法守衛答謝塔瑪拉
        political_points += 20
        F1_STATE = CLEARED
```

### 數值與表演要點

- F1 幫助者：ACT02 -10；ACT04 +20；整段完成後淨增 +10。
- F1 拒絕者：0；ACT03、ACT04 無 F1 專屬場景。
- ACT02 前五個選擇全部 0 效果；不新增追蹤旗標。
- 政治點數可在內部結算，但故事選項上不預先寫明 ACT04 將獲得 +20，以保留玩家的抉擇張力。
- 茶點插曲維持單次喜劇事件；不影響王國其他政治數值。
- 薩克迪末期制度崩潰屬學術假說的戲劇呈現；不能用旁白證實未得資料前的結論。
- 塔瑪拉不是私藏機密文獻的人；她僅可能知道合法調閱路徑或可協助取得資料。
