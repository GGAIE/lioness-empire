# 章節、幕與小節目錄

2026-10-30，依使用者確認採用可展開／收合目錄，保留現有 CG 閱讀畫面。

## 操作

首頁按「章節目錄」。點章名展開各幕，再點幕名列出小節；「展開全部」「收合全部」控制整份目錄。閱讀途中由工具列「章節」開啟，會自動展開所在的章與幕，標示閱讀中的小節；按「繼續本節」保留精確段落位置。

13章、61幕依既有規劃列出。目前可閱讀的33節為序幕8節、EP01第一至五幕各5節，第一章已提供5/5幕。已交付的幕採用正文標題，未提供的幕使用原規劃標籤並註明「規劃」「劇本尚未提供」，不編造小節。第三幕SC02至SC04及第四、五幕全部五場，各自的對話分支與共同段落亦各合為一節；DEMO及作者工作區不混入玩家目錄。

小節標示尚未閱讀／已讀／閱讀中；章與幕顯示已讀小節數。點小節可閱讀或重讀，不會因目錄點選而自動解鎖圖片或將未讀文字計入已讀。已讀紀錄來自既有玩家閱讀資料，跨存檔收藏沿用原規則。

## 選項與進度

第二幕SC03的選項、A／B／C回應及共同段落合為第三節。其他分支不列為獨立入口；一條選定路線與共同段落讀完即可標示該節已讀，不必閱讀所有分支。

尚未做出SC03選擇時，後續小節不可從目錄直接開啟。選定後重讀SC03，會顯示既有選擇及「繼續已選擇的路線」，不重新執行效果或開放改選；若要選其他方向，載入選擇前存檔或開始新的閱讀進度。

閱讀途中切換至其他小節前，先將精確段落、已選路線與數值保存至備份；若保存失敗則維持原位置。從首頁使用目錄開始時，若已有自動存檔，也先保存原自動存檔。由「存讀檔」底部「切換與遷移前的備份」可直接讀取或匯出。手動存檔不會被章節切換覆寫。

## 實作範圍

目錄由既有劇情索引、章節正文與規劃即時建立，不另維護一份重複劇本。`packages/narrative-core/directory.ts`負責分組、已讀與可閱讀路徑；`apps/web-vn/src/screens/ChapterDirectory.tsx`負責目錄畫面。CG、正文、音訊、固定選項及政治／動盪規則保持既有行為。

本次未變更劇情內容版本或存檔格式，舊玩家進度可沿用。`npm run build`更新整個`dist/`。
