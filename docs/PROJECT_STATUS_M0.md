## Canon 邊界

22 正位 + 8 逆位均建立外部 JSON 槽位和候選測試；目前 APPROVED 數量為 **0**。DRAFT / UNRESOLVED 命中仍回傳 UNRESOLVED，附候選與判定理由，不授予玩家正式結局。開發者可以在沙盒檢查全部命中、優先序覆蓋與實際值。

工程測試只代表指定測試狀態可以命中規則，不表示正式十二章劇本已使所有結局可達。人物知識界線為作者必填的結構化資料，不是自動理解或驗證文意的 AI。
