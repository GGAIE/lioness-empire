## 原稿、重新匯入與存檔

`content/reader/immersive-text-v1.json` 保存精確編輯對照；`packages/narrative-core/reader-text.ts` 將其套用於玩家版。原始來源 Markdown 與 `content/episodes` 匯入資料保留，`content:validate`／建置發佈到 `apps/web-vn/public/content` 與 `dist/content` 的內容已潤飾；客戶端載入亦做相同且可重複套用的檢查。重新匯入舊劇本不會抹掉本次編輯。

對照同時核對場景 ID、段落或選項 ID、原文；來源改變時會要求重新檢視，不做全文盲目替換。玩家內容版本附加 `.reader-v1` 以提示舊存檔更新。

舊存檔回顧僅在場景、段落 ID 及原文完全相符時同步潤飾；其他歷史文字保留。所有段落數、位置、分支、CG、說話者、政治／動盪、旗標、既有選擇與音樂維持原狀。
