# 2026-11-04 玩家介面更新

首頁改為八項正式遊戲主選單：繼續遊戲、開始遊戲、存讀檔、章節目錄、鑑賞、結局、背景音樂、設定。閱讀工具列保留必要操作並新增「返回標題」；左上角遊戲標誌也會保存進度後返回標題。

移除玩家頁面的引擎試演、瀏覽劇情架構、開發跳轉與作者工具入口，包括本機開發模式。App 不再匯入這兩個作者工具，也不再要求載入測試結局規則。試演、第一階段、草稿版等版面文字移除；未開放的故事以待續／敬請期待呈現。原始劇本狀態、審核資料與未製作內容沒有被改成核准或完成。

作弊碼入口移到頁尾右下角的 `✧`，有鍵盤焦點與 44px 點擊範圍，可用輔助功能名稱「其他選項」定位。平常不顯示密碼欄，章節目錄也不再展示解鎖區塊。密碼仍是 best，解鎖與恢復順序閱讀沿用既有偏好，不偽造已讀、圖片收藏或研究支線條件。

返回標題先保存精確自動進度，保存失敗則留在閱讀畫面。開始新的遊戲時若已有自動存檔，先確認並備份，再建立初始進度；手動槽、收藏、音樂與設定保留。新入口與舊存檔使用相同的 4175 網址。舊版測試存檔不再進入試演內容，但不刪除原檔，仍可匯出。鑑賞只列正式劇情引用的 CG，測試圖片與測試結局不顯示。

`啟動遊戲.cmd` 使用 dist 正式建置並固定 4175；首次缺少套件或建置時才準備所需檔案。舊啟動方式仍可使用，玩家介面同樣不顯示作者工具。
