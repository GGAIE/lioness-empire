## 覆蓋重點

- 封存的 v2 模型有 30 個草案候選可由測試狀態命中；此組是舊模型迴歸檢查，不表示新資源系統的三十結局已核定。原 v2；邊界包含芬利 5／6、單零／雙零、Tower T=0、愚者低 PS、早期政治死亡優先、Chariot LOST 高 F/T 不得誤判 Good、Star PS44／45。
- 核心純函式不改輸入，非法效果整筆回滾；Choice 只提交一次；歷史兩階段路線不可重新選定。
- 章節引用、Schema、POV／EP12 限制、素材型別、死路與無出口循環。
- IndexedDB API 使用 fake-indexeddb 執行單元測試，瀏覽器流程另驗實際 IndexedDB 儲存、刷新讀檔與縮圖。
- 實際點選三分支之一、Result Scene、條件選項、結局收藏與三張 CG 收藏、回顧、設定、跳轉。
- 缺圖不中斷、舊版本匯入先確認、場景映射、遷移原始備份可見。
- 使用者按鍵授權後，實際呼叫原生播放 API，確認 BGM／SFX 解碼及音量；Chromium 與 WebKit 皆通過。
- AUTO 走到選項停下、已讀跳過在第一個新段落停止、字型大小保存；手機選項邊界不與對話框重疊。
- 正式頁面無開發按鈕；輸出 JS 不含「開發場景跳轉／結局測試狀態」元件字串。

## 重跑

```sh
npm ci
npx playwright install chromium webkit
npm run content:validate
npm run content:report
npm run schema:export
npm test
npm run test:e2e
npm run build
npm run test:production
```

`test:e2e` 自動在 4180 啟動開發站，`test:production` 自動在 4181 啟動正式預覽。請先 build 再測 production。失敗時 Playwright 保留 trace 至 `test-results/`；不同測試命令會更新該目錄。一般開發不必每次重裝瀏覽器。

`docs/screenshots/` 保存桌面、Android 設定與 WebKit 設定的標題頁／選項頁截圖，已人工檢視桌面與 WebKit 圖片；發現並修正手機第三個選項被對話框遮住的佈局問題，增加選項／對話框邊界檢查。

## 實體手機點測

同一 Wi-Fi 下自行執行：

```sh
npm run dev -- --host 0.0.0.0
```

在手機開啟電腦的區域網路 IP 與 Vite 顯示的連接埠；Windows 若顯示防火牆存取提示，依實際網路設定處理。預設啟動仍僅綁定 127.0.0.1。測試聲音授權、旋轉螢幕、最大字級、存檔／匯出、切到背景再回來、關閉瀏覽器後續讀及全螢幕降級。跨來源存檔請使用匯出／匯入。
