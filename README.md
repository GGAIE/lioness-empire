獨立新增的 Vite + React + strict TypeScript 工程。保留旁邊的舊內核與 Unity 工程。已接入序幕〈母獅登基〉v0.6（8場、346段、8CG）、EP01 ACT I〈平靜被打破〉v0.3（5場、143段、11CG）、ACT II〈離開學院〉v0.2（5場、每條路線161段、20CG、一個三選一）、ACT III〈重返王都〉v0.3（5場、每條路線160–164段、20CG、三組純對話三選一）、ACT IV〈王女的職責〉v0.4（5場、每條路線140–141段、20張修正版CG、五組純對話三選一），以及ACT V〈暫時留下的人〉v0.4（5場、每條路線278–281段、20CG、五組純對話三選一）。第一章五幕均已提供，保留DRAFT；EP02起待交付。

## 開始試玩

已安裝依賴時可雙擊本目錄的 **啟動試演.cmd**，或：

```sh
npm ci
npm run dev
```

開啟終端機列出的本機網址（預設 `http://127.0.0.1:5173/`）。第一次有網路安裝套件後，遊戲本身不依賴外部 API／字型服務。手機連線說明見 `docs/TESTING.md`。

正式靜態版本：

```sh
npm run build
npm run preview
```

預設預覽 `http://127.0.0.1:4173/`。預覽沒有開發工具；部署整個 `dist/` 即可。不要以 `file://` 直接開 HTML。開發與預覽連接埠不同，瀏覽器存檔也分開；可用匯出／匯入搬移。

## 已提供

- 16:9 CG 舞台、手機排版、淡入、焦點裁切、緩慢鏡頭、圖片預載及缺圖提示。
- 逐字、點擊／空白鍵、AUTO、已讀跳過、歷史、文字速度與字型大小。
- 三選項測試、分支匯合、條件選項、純結果視角、旗標與 CLEAR、一次性效果、歷史路線鎖定。
- IndexedDB 六個手動槽、自動槽、縮圖、遷移前原始備份、匯出／匯入、版本提示與安全恢復。
- CG 收藏、三十結局槽位、已讀章節、聲音控制、全螢幕降級處理。
- 僅開發模式提供的場景跳轉、旗標檢視與結局沙盒。
- 外部 JSON + Zod + JSON Schema、單章更新、內容圖檢查、純函式結局解析、單元及瀏覽器測試。

三十個正式結局規則仍是 v2 草案，**不頒發正式結局**；命中可在開發工具追溯。唯一可收藏的測試結局與 Canon 隔離。
